# QA Portfolio – ParaBank

Functional and API testing portfolio built on **ParaBank**, a public demo
banking application by Parasoft. The goal is to show an end-to-end QA
process as I would apply it on a real project.

## About me
Functional QA Analyst based in Madrid · ISTQB CTFL certified.
4+ years of functional QA in Agile/Scrum teams, plus earlier testing work
on international multi-sport events.
[LinkedIn](https://www.linkedin.com/in/francisco-gil-gonzález-0a9bbb116)

## Scope
| Layer | Content | Status |
|-------|---------|--------|
| 1. Functional | Test plan, user stories, test cases, traceability, bug reports | In progress |
| 2. API | Postman collection with assertions, negative tests, Newman runs | Planned |
| 3. CI | Automated API test runs with GitHub Actions | Planned |

## Test techniques applied
Equivalence partitioning, boundary value analysis and exploratory testing,
following ISTQB terminology.

## Note
ParaBank is a shared public demo environment that is reset periodically.
Some issues may be environment-related; these are flagged as such in the
bug reports.
